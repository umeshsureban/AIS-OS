## Memory Rules

1. **MEMORY.md is the shared memory.** Always check it first for:
   - Active deals and prospects
   - Client statuses and contact info
   - Lessons learned
   - Communication preferences

2. **Projects folder has client details.** Check `projects/` for:
   - Full client information
   - Deal stages and probabilities
   - Action items and next steps

3. **Context folder has business info.** Check `context/` for:
   - About Umesh ji
   - AITOmate Systems overview
   - All clients and prospects summary

4. **Decisions are append-only.** Never edit `decisions/log.md` — only append.

5. **Authority boundaries are in brain.yaml.** Respect write prefixes.

6. **Use the shared authority order.** When sources overlap:
   - Live connected systems are authoritative for externally changing records.
   - `MEMORY.md` is authoritative for the latest cross-tool summary.
   - `projects/` holds detailed history, deliverables, and next steps.
   - `decisions/log.md` holds decisions and rationale.
   - `context/` holds stable identity, business, and preferences.

7. **Do not duplicate volatile state here.** Deal stages, client status, and scheduler state belong in their authoritative sources. If sources conflict, report the conflict and prefer the higher source above until reconciliation.

## End-of-Session Write-Back

At the end of every session, before concluding, **automatically write back** any meaningful changes to the vault:

1. **Client updates** → Update `projects/<client>.md` with new info
2. **Deal progression** → Update `MEMORY.md` with new stage/status
3. **Lessons learned** → Append to `decisions/log.md`
4. **New connections** → Update `connections.md`
5. **Decisions made** → Append to `decisions/log.md`

**Format for decisions/log.md append:**
```
## YYYY-MM-DD
- [Decision]: [What was decided] — [Why]
- [Lesson]: [What was learned] — [Context]
- [Action]: [What was done] — [Result]
```

**After writing back:**
```bash
cd /opt/data/ais-os-clone
git add -A
git diff --cached --quiet || git commit --quiet -m "chore(write-back): session $(date -u +%FT%TZ)"
git push --quiet || true
```
